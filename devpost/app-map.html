2. Key Code Stops

  • Stop 1 — Mobile UI & Touch Dock: public/index.html — Contains the responsive 4-tab mobile view, Apple Fitness progress ring, 7-day micro-heatmaps, and bottom sheet drawer.
  • Stop 2 — Gemini Multi-Persona Engine: routes/coach.js — Handles prompt formatting for Stoic, Tough Love, Hype, and Empathetic personas, with automatic model fallback (gemini-3.5-flash-lite, gemini-3.8-flash).
  • Stop 3 — Store Deployment Packaging: capacitor.config.json — Configures the native Android Studio (android/) and iOS Xcode (ios/) packages.

3. A Practice to Reuse

Plan with thin end-to-end slices: Rather than spending days building an entire native mobile app before testing, building in vertical slices (core checklist ➔ interactive chimes ➔ AI coaching ➔ native packaging) ensured runnable evidence at every step and bad news arrived early.

4. How to Run & Build

# Start local mobile web server
npm install
node server.js

# Sync with Android Studio for Google Play APK
npx cap sync
npx cap open android

# Sync with Xcode for Apple App Store
npx cap open ios
